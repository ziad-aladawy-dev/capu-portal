## Part 4: Close/Reopen Record in RequestReview

### File: `frontend/src/modules/studentServices/pages/admin/RequestReview.jsx`

Add two new action buttons in the right sidebar:

1. **Close Record** button — visible when:
   - Request status is `Completed` or `Cancelled`
   - Request is NOT already closed (`!currentRequest.isClosed`)
   - Staff has `student-services.requests.EditClose` permission
   - Shows a `ConfirmDialog` before closing

2. **Reopen Record** button — visible when:
   - Request IS closed (`currentRequest.isClosed`)
   - Staff has `student-services.requests.Open` permission
   - Shows a `ConfirmDialog` before reopening

### Service layer additions

```js
export const closeRecord = async (requestId) => {
  const response = await apiClient.post(`${BASE_URL}/requests/${requestId}/close-record`);
  return response.data;
};

export const openRecord = async (requestId) => {
  const response = await apiClient.post(`${BASE_URL}/requests/${requestId}/open-record`);
  return response.data;
};
```

### Hook additions: `useStaffRequests.js`

```js
const closeMutation = useMutation({
  mutationFn: (requestId) => closeRecord(requestId),
  onSuccess: () => {
    queryClient.invalidateQueries({ queryKey: [REQUESTS_KEY] });
    queryClient.invalidateQueries({ queryKey: ["staff-dashboard"] });
  },
});

const openMutation = useMutation({
  mutationFn: (requestId) => openRecord(requestId),
  onSuccess: () => {
    queryClient.invalidateQueries({ queryKey: [REQUESTS_KEY] });
    queryClient.invalidateQueries({ queryKey: ["staff-dashboard"] });
  },
});
```

Expose: `closeRecord: (requestId) => closeMutation.mutateAsync(requestId)` and `openRecord: (requestId) => openMutation.mutateAsync(requestId)`.

### RequestReview.jsx changes

- Import `ConfirmDialog` from core
- Add close/reopen section below the status action card
- Show `isClosed` badge on the request if closed
- Wire close/open mutations with toast feedback

### i18n keys

`close_record`, `open_record`, `record_closed`, `record_reopened`, `confirm_close_message`, `confirm_open_message`, `closed_record`
